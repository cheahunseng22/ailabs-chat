# AI Streaming Chat Application

## ✨ Features
- **Live chat interface** with streaming AI responses
- **Typewriter effect** – text appears character by character left-to-right
- **Chat history** – all conversations saved to localStorage
- **View & restore** previous chats from sidebar
- **Delete chats** you no longer need
- **New chat button** creates fresh conversation
- Modern glassmorphic UI design
- Fully responsive layout
